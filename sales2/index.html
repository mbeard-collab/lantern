This dashboard automates what's available in CrateDB. The following data doesn't exist in the database yet — the answers below will determine whether it can be added to the sync or needs a different approach.

  1. 1
    Stage filter for new business — This dashboard filters to: Opportunity Identified, Demo/Needs Analysis, Trial, Proposal Sent/Negotiating, Finalizing Contract. Are these the correct stages for new business? Do any renewals appear in these stages?
  2. 2
    Push count — The original shows how many times each deal's close date has been pushed. Is pushCount a Salesforce field, or is it computed by comparing daily close-date snapshots?
  3. 3
    Next step — The original shows nextStep notes per deal. Is this the Salesforce standard NextStep field? If so, it can likely be added to the CrateDB sync.
  4. 4
    Trial indicator — The original flags deals that have had a trial (hasTrial). Is this from stage progression history, from a platform trial table, or an explicit Salesforce field?
  5. 5
    Effective start date — The original shows a contract start date separate from close date. Is this a custom Salesforce field (e.g. Effective_Start_Date__c)? Can it be added to the sync?
  6. 6
    Opportunity scores — Each deal has a composite score (Trial=30pts, Stage momentum, ACV, Rep track record, Next step quality, Push penalty). Is this scoring run by Claude each day using a rubric, or a coded algorithm we could replicate here?
  7. 7
    Quota data — The original shows YTD attainment vs quota per AE, SDR, and pod. Where does quota data live? Salesforce quota objects, a spreadsheet, or manually maintained?
  8. 8
    SDR attribution — The original credits SDRs for sourcing closed-won deals. Is there an Originator__r.Name (or similar) field in Salesforce? Can it be added to the sync?
  9. 9
    Delta tracking (PREV_RUN) — The original shows which deals moved, slipped, or disappeared since the last run. Is the previous-run state stored somewhere as a file, or does Claude rebuild it from context each time?
